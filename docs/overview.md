# Overview

Status: specified, not built. The product is decided
([D-0003](decisions.md#d-0003)). The shell is Electron 45
([D-0004](decisions.md#d-0004), [D-0011](decisions.md#d-0011)).

`lv-desktop` is a single-window desktop client for Lingvist. It is
for someone sitting at a desk, with a keyboard and a large display.
That is the better place to drill vocabulary. A phone or a tablet is
the worse place, and this client does not try to feel like them.

Lingvist stays the teacher. The window opens the study site. The
shell keeps the session, stays out of the keyboard, and shortens one
fixed pause after a correct answer.

The name follows the workspace directory. There is no application
code yet.
