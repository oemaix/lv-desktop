# Security policy

lv-desktop is a desktop shell on your machine. It does not run a
service, and it does not keep an account of its own. The study site
still receives what you type there.

## Supported versions

There is no packaged release. The `main` branch is the only
supported line.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository.

If that channel is not available, open a public issue only when the
report contains no session file, token, password, or working
exploit.

Include the operating system, the command you used to start the
app, and what the window did.

A report is handled when a maintainer sees it. There is no bounty.
